# Spectrum

Spectrum is a color toolkit for designers and developers: color picking, format conversion, palettes, gradients, contrast checking and image color sampling. Use it in the browser at **[spectrum.samolevsky.com](https://spectrum.samolevsky.com/)** or install the desktop app.

## Download

Get the newest version from the **[latest release](https://github.com/Samolevsky/Spectrum-Releases/releases/latest)**:

| Computer | File |
| --- | --- |
| Mac with Apple Silicon (M1 and newer) | `Spectrum-<version>-mac-arm64.dmg` |
| Mac with Intel processor | `Spectrum-<version>-mac-intel.dmg` |
| Windows 10/11 (64-bit) | `Spectrum-<version>-win-x64.exe` |

On a Mac, open the `.dmg` and drag Spectrum to Applications. On Windows, run the installer; if SmartScreen warns about an unrecognized app, choose **More info › Run anyway**.

## Updating

Spectrum checks for updates shortly after it starts. You can also check any time:

- **macOS:** Spectrum › Check for Updates…
- **Windows:** Help › Check for Updates…

Confirm the download, then restart now or let the update install the next time you quit. **Help › Release Notes** shows what changed.

## Source code

This repository only hosts installers and the update feed. Spectrum's source code is not public.
